# Colors LAMP Website

## Description
This is a respository for a website that that allows users to login, where they can add any colors of their choice and later search for those colors.

## Technologies Used
Below are the following Technologies used to run this website:
- Operating System: Ubuntu 24.04.3 LTS 
- Apache 2.4.58 (Ubuntu)
- PHP 8.4.15
- MySQL 8.0.45-0ubuntu0.24.04.1 (Ubuntu)
